## ⚠️ Внимание: Ограничение GitHub

Из-за ограничений GitHub (максимум 100 МБ на файл), файлы лабораторной работы были разбиты на части.

Файлы `lab6_1.aup3` и`lab6_2.aup3` разбиты на несколько фрагментов (`lab6_1.aup3.part_aa`, `lab6_1.aup3.part_ab`, и т.д.).

---

## 🛠 Как восстановить оригинальный файл

### 1. Убедитесь, что у вас установлен `cat`.

Oбычно уже есть в Linux/macOS, для Windows — используйте Git Bash или WSL

### 2. Выполните команду в терминале в папке с файлами:

```bash
cat lab6_1.aup3.part_* > lab6_1.aup3
cat lab6_2.aup3.part_* > lab6_2.aup3
```
После выполнения вы получите полноценный файлы `lab6_1.aup3` и `lab6_2.aup3`.
