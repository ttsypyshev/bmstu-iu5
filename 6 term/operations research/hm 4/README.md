**Входные данные:**

### Входные Данные (Вариант Задания)

**1. Целевая Функция:**
$f(x,y) = -10x - 10y$

Требуется найти **точную нижнюю грань** (минимум) этой функции.

**2. Система Неравенств (C), Задающая Допустимое Множество $X$:**
1.  $171 + 22x + 3y \ge 0 \quad \Rightarrow \quad -22x - 3y \le 171$
2.  $156 - 6x + 12y \ge 0 \quad \Rightarrow \quad 6x - 12y \le 156 \quad \Rightarrow \quad x - 2y \le 26$
3.  $95 + 7x + 9y \ge 0 \quad \Rightarrow \quad -7x - 9y \le 95$
4.  $44 + 6x - 4y \ge 0 \quad \Rightarrow \quad -6x + 4y \le 44 \quad \Rightarrow \quad -3x + 2y \le 22$
5.  $90 - 9x - 9y \ge 0 \quad \Rightarrow \quad 9x + 9y \le 90 \quad \Rightarrow \quad x + y \le 10$

Переменные $x$ и $y$ **без ограничений по знаку**.

## Математические Формулы и Расчеты

### 1. Каноническая Форма Задачи Линейного Программирования

Общая задача линейного программирования в канонической форме выглядит так:

**Минимизировать:**
$c^T x$

**При ограничениях:**
$Ax = b$
$x \ge 0$

Где:
* $c$ — вектор коэффициентов целевой функции.
* $x$ — вектор переменных.
* $A$ — матрица коэффициентов ограничений.
* $b$ — вектор правых частей ограничений.

#### Преобразование Исходной Задачи:

1.  **Целевая Функция:** Исходная функция $f(x,y) = -10x - 10y$ уже является функцией минимизации. Коэффициенты $c = [-10, -10]$.

2.  **Переменные без ограничений по знаку:** Поскольку $x$ и $y$ могут принимать любые значения, введем новые неотрицательные переменные:
    $x = x^+ - x^-$
    $y = y^+ - y^-$
    где $x^+, x^-, y^+, y^- \ge 0$.
    Тогда целевая функция становится:
    $f = -10(x^+ - x^-) - 10(y^+ - y^-) = -10x^+ + 10x^- - 10y^+ + 10y^-$

3.  **Ограничения-неравенства в ограничения-равенства:** Каждое неравенство $\le$ преобразуется в равенство путем добавления неотрицательной слабой переменной ($s_i \ge 0$).
    Например, для неравенства $-22x - 3y \le 171$, мы добавляем слабую переменную $s_1$:
    $-22x - 3y + s_1 = 171$
    Подставляя $x = x^+ - x^-$ и $y = y^+ - y^-$:
    $-22(x^+ - x^-) - 3(y^+ - y^-) + s_1 = 171$
    $-22x^+ + 22x^- - 3y^+ + 3y^- + s_1 = 171$

    Таким образом, система ограничений-неравенств преобразуется в следующую систему ограничений-равенств:
    1.  $-22x^+ + 22x^- - 3y^+ + 3y^- + s_1 = 171$
    2.  $x^+ - x^- - 2y^+ + 2y^- + s_2 = 26$
    3.  $-7x^+ + 7x^- - 9y^+ + 9y^- + s_3 = 95$
    4.  $-3x^+ + 3x^- + 2y^+ - 2y^- + s_4 = 22$
    5.  $x^+ - x^- + y^+ - y^- + s_5 = 10$

    Все переменные $x^+, x^-, y^+, y^-, s_1, s_2, s_3, s_4, s_5$ должны быть $\ge 0$.

    Таким образом, мы получаем:
    * Вектор коэффициентов целевой функции $c$: $c = [-10, 10, -10, 10, 0, 0, 0, 0, 0]$ (для переменных $x^+, x^-, y^+, y^-, s_1, s_2, s_3, s_4, s_5$).
    * Матрица $A$: Коэффициенты при переменных в системе равенств.
    * Вектор $b$: Правые части равенств: $b = [171, 26, 95, 22, 10]^T$.

### 2. Графическое Решение

Для двух переменных ($x, y$), допустимая область $X$ является многоугольником на плоскости (выпуклый многогранник).
* Каждое неравенство представляет собой полуплоскость. Пересечение этих полуплоскостей образует допустимую область.
* Линии уровня функции $f(x,y) = C$ (где $C$ - константа) представляют собой прямые линии: $-10x - 10y = C \Rightarrow x + y = -C/10$.
* Чтобы найти минимум функции, мы "двигаем" линии уровня в направлении уменьшения $f(x,y)$ (в данном случае, в сторону отрицательных значений $x$ и $y$) до тех пор, пока линия уровня не коснется допустимой области в последней точке. Эта точка (или множество точек) является оптимальным решением.

### 3. Численное Решение с `scipy.optimize.linprog`

Функция `scipy.optimize.linprog` решает задачи линейного программирования в форме:

**Минимизировать:**
$c^T x$

**При ограничениях:**
$A_{ub} x \le b_{ub}$ (ограничения-неравенства)
$A_{eq} x = b_{eq}$ (ограничения-равенства)
$l \le x \le u$ (границы переменных)

Где $l$ и $u$ - нижние и верхние границы переменных.

Для нашей задачи:
* **`c`**: Вектор коэффициентов целевой функции $[-10, -10]$ (для $x, y$).
* **`A_ub`**: Матрица коэффициентов для неравенств $\le$. Это коэффициенты $A_{ij}$ из преобразованных неравенств:
    $A_{ub} = \begin{pmatrix}
    -22 & -3 \\
    1 & -2 \\
    -7 & -9 \\
    -3 & 2 \\
    1 & 1
    \end{pmatrix}$
* **`b_ub`**: Вектор правых частей неравенств $\le$: $b_{ub} = [171, 26, 95, 22, 10]^T$.
* **`bounds`**: Для $x, y$ - без ограничений по знаку, поэтому `bounds=(None, None)` для каждой переменной.

Результат `linprog` включает:
* `fun`: Оптимальное значение целевой функции.
* `x`: Вектор значений переменных, при которых достигается оптимум.
* `status`: Статус решения (успех, неразрешимость и т.д.).
