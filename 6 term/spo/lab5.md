## **3.2.1 Установка и настройка виртуальной машины ws1-alt10**

### 1. Импорт виртуальной машины

* Запустите **Oracle VM VirtualBox**
* В меню выберите **Файл → Импорт конфигурации**
* Укажите путь к файлу:

  ```
  \home\OC-СПО\Сети Alt\ws1-alt10.ova
  ```
* Следуйте шагам мастера импорта и завершите установку

### 2. Настройка сети

* Выделите `ws1-alt10` → нажмите **Настроить (Settings)** → вкладка **Сеть (Network)**

  * **Адаптер 1:**

    * Включить адаптер
    * Тип подключения: **NAT**
  * **Адаптер 2:**

    * Включить адаптер
    * Тип подключения: **Внутренняя сеть**
    * Имя сети: `intnet` (можно задать вручную)

### 3. Запуск рабочей станции

* Запустите виртуальную машину `ws1-alt10`
* Войдите под пользователем:

  * **Пользователь:** `admin_ws`
  * **Пароль:** `adminws`

## **3.2.2 Настройка сетевых интерфейсов ws1-alt10**

### Задача:

* **enp0s3** – динамический IP (DHCP) от VirtualBox (NAT)
* **enp0s8** – статический IP: `192.168.100.101/24`

### Порядок действий:

1. Получите root-доступ:

   ```bash
   su
   ```

   Введите пароль root (предустановленный)

2. Установите `netplan`:

   ```bash
   apt-get update && apt-get install netplan -y
   ```

   ```bash
   export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
   ```

3. Создайте YAML-файл конфигурации сети:

   ```bash
   nano /etc/netplan/config.yaml
   ```

   **Содержимое файла:**

   ```yaml
   network:
     version: 2
     renderer: NetworkManager
     ethernets:
       enp0s3:
         dhcp4: true
       enp0s8:
         addresses: [192.168.100.101/24]
   ```

   ```bash
   chmod 600 /etc/netplan/config.yaml
   ```

4. Примените конфигурацию:

   ```bash
   netplan apply
   ```

5. Проверьте:

   ```bash
   ip a
   ```

## **3.2.6 Настройка SSH**

1. На сервере:

   ```bash
   adduser admin_ssh
   ```

   ```bash
   apt-get update && apt-get install openssh-server -y
   ```

2. Проверка статуса SSH:

   ```bash
   systemctl status sshd
   passwd admin_ssh
   ```
   И задайте пароль, например `Admin_ssh123`

3. Включение SSH при необходимости:

   ```bash
   systemctl enable sshd
   systemctl start sshd
   ```

4. Изменение порта (например, 2222):

   * Откройте конфиг:

     ```bash
     nano /etc/openssh/sshd_config
     ```
   * Найдите строку:

     ```bash
     Port 22
     ```

     и замените на:

     ```bash
     Port 2222
     ```
   * Перезапустите SSH:

     ```bash
     systemctl restart sshd
     ```

5. На рабочей станции:

   ```bash
   ssh admin_ssh@192.168.100.100 -p 2222
   ```

6. Завершение соединения:

   ```bash
   exit
   ```
