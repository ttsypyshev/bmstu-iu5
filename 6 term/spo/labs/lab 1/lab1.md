### **1. Импорт виртуальной машины `ws1-ubuntu2204`**

**Файл образа:**
`D:\OC\Сети Ubuntu2204\ws1-ubuntu2204.ova`

**Шаги:**

1. Откройте VirtualBox.
2. Перейдите в меню **Файл → Импорт конфигурации виртуальной машины**.
3. Выберите файл `ws1-ubuntu2204.ova` и нажмите **Далее**.
4. Убедитесь в правильности параметров и нажмите **Импорт**.

---

### **2. Настройка виртуальной машины `ws1-ubuntu2204`**

**Сетевые адаптеры:**

* **Адаптер 1:**

  * Включить
  * Тип подключения: **NAT**
* **Адаптер 2:**

  * Включить
  * Тип подключения: **Внутренняя сеть**
  * Имя сети: например, `intnet`

**Настройка:**

1. Выделите VM → **Настроить → Сеть**.
2. Активируйте **Адаптер 1** и выберите NAT.
3. Активируйте **Адаптер 2**, выберите "Внутренняя сеть", задайте имя (например, `intnet`).

---

### **3. Запуск виртуальной машины `ws1-ubuntu2204`**

**Данные входа:**

* Пользователь: `admin_ws`
* Пароль: `adminws`

---

### **4. Настройка сетевых интерфейсов**

**Файл конфигурации:** `/etc/netplan/01-netcfg.yaml`

**enp0s3 (NAT – доступ в интернет):**

* Обычно активируется автоматически через DHCP.
* Проверка:

  ```bash
  ip a show enp0s3
  ```

**enp0s8 (внутренняя сеть – статический IP):**

1. Открыть файл:

   ```bash
   sudo nano /etc/netplan/01-netcfg.yaml
   ```

2. Пример конфигурации:

   ```yaml
   network:
     version: 2
     renderer: networkd
     ethernets:
       enp0s3:
         dhcp4: true
       enp0s8:
         addresses: [192.168.100.101/24]
   ```

3. Применить изменения:

   ```bash
   sudo netplan apply
   ```

### **9. Настройка общего доступа к папке**

1. Открыть графический интерфейс.
2. Перейти к `/common_ws1`.
3. Правый клик → **Свойства → Общий доступ**.
4. Отметить:

   * Открыть общий доступ
   * Разрешить создание и удаление
   * Разрешить доступ без учётной записи
   * Указать имя ресурса: `common_ws1`

В облее новых версиях:
```bash
    sudo nano /etc/samba/smb.conf

    [common_ws1]
        path = /common_ws1
        browsable = yes
        writable = yes
        guest ok = yes
        force user = admin_ws

    sudo systemctl restart smbd

```

### **1. В чём заключается настройка сетевых интерфейсов рабочих станций сети?**

Настройка сетевых интерфейсов рабочих станций заключается в:

* Выборе режима получения IP-адреса: **автоматически (DHCP)** или **вручную (статически)**.
* Указании параметров, если IP-адрес задаётся вручную:

  * IP-адрес;
  * Маска подсети (обычно `255.255.255.0`);
  * Шлюз по умолчанию (если требуется выход в интернет);
  * DNS-серверы.
* В Ubuntu (через GUI):

  * «Настройки» → «Сеть» → выбрать интерфейс → «Настроить» → вкладка «IPv4».
* В Ubuntu (через терминал и Netplan, если используется):
  Файл конфигурации `/etc/netplan/*.yaml`:

  ```yaml
  network:
    version: 2
    ethernets:
      enp0s3:
        addresses: [192.168.1.10/24]
        gateway4: 192.168.1.1
        nameservers:
          addresses: [8.8.8.8, 8.8.4.4]
  ```

  Команда для применения:

  ```
  sudo netplan apply
  ```

### **2. В каких случаях удобно использование статических IP-адресов рабочих станций?**

Статические IP-адреса удобны, когда:

* Рабочая станция выполняет **сервисные функции** (например, файловый сервер, принт-сервер).
* Требуется **устойчивое соединение** с конкретным хостом (например, для SSH-подключения).
* В сети **отсутствует DHCP-сервер**.
* Важно обеспечить **предсказуемость** и **удобство администрирования** (например, для резервного копирования по IP).
* Сеть **маленькая и статичная**, с небольшим числом узлов.

### **3. Как создать каталог и обеспечить общий доступ к нему по сети?**

На Ubuntu это можно сделать с помощью **Samba** — службы для общего доступа к папкам и файлам между Linux и Windows.

#### Пример действий:

1. **Установить Samba**:

   ```
   sudo apt update
   sudo apt install samba
   ```

2. **Создать общий каталог**:

   ```
   mkdir -p /home/username/shared
   chmod 777 /home/username/shared
   ```

3. **Настроить Samba**:
   Открыть файл конфигурации:

   ```
   sudo nano /etc/samba/smb.conf
   ```

   Добавить в конец:

   ```
   [Shared]
     path = /home/username/shared
     browsable = yes
     writable = yes
     guest ok = yes
     read only = no
   ```

4. **Перезапустить Samba**:

   ```
   sudo systemctl restart smbd
   ```

5. **Проверить доступ**:
   С другого компьютера в сети:

   ```
   smb://IP_адрес_хоста/Shared
   ```

   Или в Windows — через «Выполнить» (Win + R):

   ```
   \\IP_адрес_хоста\Shared
   ```
