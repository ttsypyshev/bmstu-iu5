## **3.2.1 Установка сервера `server-ubuntu2204`**

### **Шаг 1: Импорт виртуальной машины**

1. Откройте VirtualBox.
2. Выберите: **Файл → Импорт конфигурации виртуальной машины**
3. Укажите путь:
   `D:\ОС\Сети Ubuntu2204\server-ubuntu2204.ova`
4. Нажмите **Далее** → **Импортировать**.

---

### **Шаг 2: Настройка сети виртуальной машины**

1. Откройте **Настройки** → **Сеть**:

   * **Адаптер 1**: Включить, Тип подключения: `NAT`
   * **Адаптер 2**: Включить, Тип подключения: `Внутренняя сеть`

---

### **Шаг 3: Запуск и вход в систему**

1. Запустите ВМ `server-ubuntu2204`
2. Введите логин/пароль:
   **Логин:** `admin_server`
   **Пароль:** `adminserver`

---

## **3.2.2 Настройка сетевых интерфейсов**

### **Интерфейс `enp0s3` (внешняя сеть):**

* Подключается автоматически через DHCP (через NAT).
* Проверка:

  ```bash
  ping ya.ru
  ```

  Нажмите `Ctrl+Z` для остановки.

### **Интерфейс `enp0s8` (локальная сеть):**

1. Назначьте **статический IP** — например, `192.168.100.100`.
2. Измените файл `/etc/netplan/00-installer-config.yaml`, например:

   ```yaml
   network:
     version: 2
     ethernets:
       enp0s3:
         dhcp4: true
       enp0s8:
         addresses: [192.168.100.100/24]
   ```
3. Примените настройки:

   ```bash
   sudo netplan apply
   ```

---

### **Проверка `enp0s8`**

1. Запустите ВМ `ws1-ubuntu`
2. В терминале:

   ```bash
   ping 192.168.100.100
   ```

   Нажмите `Ctrl+Z` для остановки.

---

## **3.2.3 Установка Webmin**

### **Установка Webmin на сервере:**

1. Запустите `server-ubuntu2204`
2. Выполните в терминале (см. пункт 6.2 приложения, например):

   ```bash
   sudo apt update
   sudo apt install wget apt-transport-https
   wget -qO - http://www.webmin.com/jcameron-key.asc | sudo apt-key add -
   sudo add-apt-repository "deb http://download.webmin.com/download/repository sarge contrib"
   sudo apt update
   sudo apt install webmin
   ```

---

## **3.2.4 Удалённый доступ к Webmin**

1. На `ws1-ubuntu` откройте Firefox
2. Введите в адресную строку:

   ```
   https://192.168.100.100:10000
   ```
3. Нажмите "Дополнительно" → "Принять риск и продолжить"
4. Введите логин/пароль:

   ```
   Логин: admin_server
   Пароль: adminserver
   ```

---

### **Изменение языка Webmin на русский**

1. В Webmin откройте **Webmin → Change Language and Theme**
2. Нажмите **Personal choice**
3. Выберите язык: **Русский**
4. Нажмите **Make Changes**

## **3.2.5 Установка SSH-сервера**

### **1. Создание учётной записи admin_ssh**

```bash
sudo adduser admin_ssh
sudo usermod -aG sudo admin_ssh
```

---

### **2. Установка модуля SSH в Webmin**

1. Откройте Webmin
2. **Неиспользуемые модули → Сервер SSH**
3. Нажмите **Установить сейчас**
4. После установки нажмите **Обновить модули**

---

## **3.2.6 Настройка SSH-сервера**

1. В Webmin:

   * Откройте **Службы → Сервер SSH**
   * Перейдите в **Аутентификация**
     * **Разрешить регистрацию для root**: `Нет` → Сохранить

   * Перейдите в **Сеть**
     * Слушать по адресу: `192.168.100.100`, порт: `22` → Сохранить

   * Перейдите в **Управление доступом**
     * Снимите галочку **Разрешить только пользователям**
     * Укажите пользователя `admin_ssh` → Сохранить
     
   * Нажмите **Применение изменений**

---

## **3.2.7 Удалённый вход по SSH**

1. На `ws1-ubuntu` откройте терминал:

   ```bash
   ssh admin_ssh@192.168.100.100
   ```
2. При первом подключении:

   ```
   yes
   adminssh (ввести пароль)
   ```

### **1. Какие функции выполняет Ubuntu Server?**

**Ubuntu Server** — это серверная редакция ОС Ubuntu, предназначенная для работы без графического интерфейса. Она выполняет следующие функции:

* **Хостинг веб-сайтов** (например, через Apache, Nginx);
* **Файл-сервер** (через Samba, FTP, NFS);
* **Сервер баз данных** (MySQL, PostgreSQL, MongoDB и др.);
* **Почтовый сервер** (Postfix, Dovecot и др.);
* **SSH-сервер** — удалённое управление по сети;
* **DNS, DHCP-сервер** — служебные сетевые службы;
* **Контейнеризация и виртуализация** (через Docker, KVM);
* **Облачные и DevOps решения** (OpenStack, Kubernetes и др.).

Ubuntu Server — это надёжная основа для развёртывания различных сетевых и корпоративных сервисов.

---

### **2. Для чего предназначен web-интерфейс Webmin?**

**Webmin** — это **веб-интерфейс для администрирования серверов Linux/Unix**.

С его помощью можно:

* Настраивать **пользователей и группы**;
* Управлять **службами и процессами**;
* Конфигурировать **сетевые настройки** и **файлы конфигурации**;
* Управлять **брандмауэром**, **SSH**, **Apache**, **Samba**, **Postfix** и другими сервисами;
* Обновлять пакеты и контролировать состояние системы;
* Проводить **администрирование удалённо через браузер**.

Главное преимущество — **управление сервером без необходимости использовать командную строку**.

---

### **3. В чём особенность сетевого протокола SSH?**

**SSH (Secure Shell)** — это **протокол удалённого управления** системами по сети с **повышенной безопасностью**.

Его особенности:

* **Шифрование трафика** — защищает от перехвата данных;
* **Аутентификация** — по паролю или с использованием SSH-ключей;
* **Передача файлов** (через `scp`, `sftp`);
* **Проброс портов** — создание защищённых туннелей;
* Используется для **удалённого доступа к командной строке** Linux/Unix-систем.

SSH — это стандарт для безопасного администрирования серверов и сетевых устройств.
