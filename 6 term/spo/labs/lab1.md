### **1. Импорт виртуальной машины `ws1-ubuntu2204`**

**Файл образа:**
`D:\OC\Сети Ubuntu2204\ws1-ubuntu2204.ova`

**Шаги:**

1. Откройте VirtualBox.
2. Перейдите в меню **Файл → Импорт конфигурации виртуальной машины**.
3. Выберите файл `ws1-ubuntu2204.ova` и нажмите **Далее**.
4. Убедитесь в правильности параметров и нажмите **Импорт**.

---

### **2. Настройка виртуальной машины `ws1-ubuntu2204`**

**Сетевые адаптеры:**

* **Адаптер 1:**

  * Включить
  * Тип подключения: **NAT**
* **Адаптер 2:**

  * Включить
  * Тип подключения: **Внутренняя сеть**
  * Имя сети: например, `intnet`

**Настройка:**

1. Выделите VM → **Настроить → Сеть**.
2. Активируйте **Адаптер 1** и выберите NAT.
3. Активируйте **Адаптер 2**, выберите "Внутренняя сеть", задайте имя (например, `intnet`).

---

### **3. Запуск виртуальной машины `ws1-ubuntu2204`**

**Данные входа:**

* Пользователь: `admin_ws`
* Пароль: `adminws`

---

### **4. Настройка сетевых интерфейсов**

**Файл конфигурации:** `/etc/netplan/01-netcfg.yaml`

**enp0s3 (NAT – доступ в интернет):**

* Обычно активируется автоматически через DHCP.
* Проверка:

  ```bash
  ip a show enp0s3
  ```

**enp0s8 (внутренняя сеть – статический IP):**

1. Открыть файл:

   ```bash
   sudo nano /etc/netplan/01-netcfg.yaml
   ```

2. Пример конфигурации:

   ```yaml
   network:
     version: 2
     renderer: networkd
     ethernets:
       enp0s3:
         dhcp4: true
       enp0s8:
         addresses: [192.168.100.101/24]
   ```

3. Применить изменения:

   ```bash
   sudo netplan apply
   ```

### **7. Установка Samba**

На **обеих** рабочих станциях:

```bash
sudo apt update
sudo apt install samba -y
```

---

### **8. Создание общего каталога `common_ws1` на `ws1-ubuntu2204`**

1. Создание папки:

   ```bash
   sudo mkdir /common_ws1
   sudo chown admin_ws:admin_ws /common_ws1
   sudo chmod 777 /common_ws1
   ```

---

### **9. Настройка общего доступа к папке**

1. Открыть графический интерфейс.
2. Перейти к `/common_ws1`.
3. Правый клик → **Свойства → Общий доступ**.
4. Отметить:

   * Открыть общий доступ
   * Разрешить создание и удаление
   * Разрешить доступ без учётной записи
   * Указать имя ресурса: `common_ws1`

В облее новых версиях:
```bash
    sudo nano /etc/samba/smb.conf

    [common_ws1]
        path = /common_ws1
        browsable = yes
        writable = yes
        guest ok = yes
        force user = admin_ws

    sudo systemctl restart smbd

```

---

### **10. Подключение к общей папке с `ws2-ubuntu2204`**

1. Открыть домашнюю папку.
2. Выбрать **+ Другие места**.
3. В разделе **Сеть** найти `WS1-UBUNTU2204`.
4. Открыть папку `common_ws1`.
5. Ввести данные (если требуется):

   * Пользователь: `admin_ws`
   * Пароль: `adminws`
