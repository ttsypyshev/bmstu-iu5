# CIFAR-100 Classification Web App

Веб-приложение для классификации изображений с использованием нейросети ResNet20. Проект состоит из скрипта экспорта модели (Python) и сервера (Go).

## Основные компоненты
- **Модель**: ResNet20 (CIFAR-100), формат ONNX.
- **Backend**: Go + ONNX Runtime.
- **Frontend**: Интерфейс для загрузки и анализа изображений.

## Инструкция по запуску

### 1. Подготовка модели (Python)
Рекомендуется использовать виртуальное окружение.
```bash
# Установка зависимостей
pip install -r requirements.txt

# Экспорт модели
python init.py
```
В корне появится файл `cifar100_resnet20.onnx`.

### 2. Запуск сервера (Go)
1. Убедитесь, что файл библиотеки `libonnxruntime.dylib` (macOS), `onnxruntime.dll` (Windows) или `libonnxruntime.so` (Linux) находится в корне проекта.
2. Запустите сервер:
```bash
go mod tidy
go run main.go
```
Приложение будет доступно по адресу: `http://localhost:8080`

## Структура
- `init.py` — экспорт модели из PyTorch в формат ONNX.
- `main.go` — серверная логика, препроцессинг и инференс.
- `requirements.txt` — список зависимостей Python.
- `templates/` — HTML-шаблоны интерфейса.
- `static/` — статические файлы и временные изображения.

## Возможные проблемы
- **SSL Error (macOS)**: Ошибка при скачивании весов. В `init.py` добавлен обход проверки сертификатов, но может потребоваться выполнение `Install Certificates.command` в папке установки Python.
- **Library not found**: Ошибка инициализации ONNX Runtime в Go. Убедитесь, что путь к динамической библиотеке в `main.go` указан верно для вашей ОС.
- **Architecture mismatch**: Использование библиотеки для другой архитектуры (например, x86_64 на Apple M1). Проверьте версию скачанного рантайма.
- **macOS Security**: Блокировка `.dylib` системой. Разрешите запуск в разделе «Конфиденциальность и безопасность» системных настроек.
