## Цели репозитория

Репозиторий создан для систематизации и хранения учебных материалов, а также для отслеживания прогресса и развития профессиональных навыков.
Материалы могут быть полезны не только автору, но и другим студентам, изучающим аналогичные дисциплины или выполняющим схожие проекты. Однако полное их копирование не приветствуется - попробуйте разобраться сами.
